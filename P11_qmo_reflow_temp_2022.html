基于量子多目标优化算法的回焊炉炉温设计

Design of reflow oven furnace temperature based on quantum multi-objective optimization algorithm

周文婷，司玉鹏，何宏舟，王荣杰 - 焊接学报（Transactions of the China Welding Institution）2022, 43(1): 85-91, 集美大学

DOI: 10.12073/j.hjxb.20210508001 | 收稿: 2021-05-08 | 出版: 2022-01

关键词：炉温曲线（Furnace Temperature Curve）; 量子粒子群算法（Quantum Particle Swarm Optimization）; 多目标优化（Multi-objective Optimization）; 傅里叶定律（Fourier's Law）; 加热因子（Heating Factor）

研究摘要

本文针对回焊炉（reflow oven）炉温曲线的多目标优化问题，建立了电路板焊接中心的非稳态导热模型，并引入量子多目标粒子群算法（QMOPSO）进行求解，核心成果可概括为：

  • 建模路线：基于 傅里叶定律（Fourier's Law） 与 集总参数法（Lumped Parameter Method） 建立焊接中心温度变化模型，并采用牛顿冷却定律描述表面换热，相比纯数值差分方法计算量大幅降低。
  • 双目标设计：在满足制程界限与工艺要求的约束下，同时优化「传送带过炉速度最大」与「加热因子（Heating Factor）最小」两个冲突目标，由模糊隶属函数从帕累托（Pareto）解集中挑选最终方案。
  • 关键结果：优化后过炉速度 95.55 cm/min（接近上限 100）、最小加热因子 1753.04、峰值温度 240.01 ℃（接近制程下限 240）——炉温曲线先升后降且整体紧贴制程窗口，兼顾焊接质量与生产效率。
  • 工程意义：模型同时得到各温区最优温度设定，为实际回焊炉温区配置提供可直接参考的参数表。
Note

为什么"双目标"是本文的卖点：现有工作普遍做单目标优化——要么只最小化加热因子（牺牲产量），要么只最大化传送带速度（牺牲焊接质量，液相线以上时间过长）。本文用多目标 Pareto 前沿一次给出整个权衡曲线，再按模糊隶属度选点，既避免人为定权重的随意性，又把"速度—质量"这一对工程上最纠结的矛盾显式摆到了解集里，这是它区别于序言评点的既往炉温优化工作（参考文献 [7]–[12]，详见整理表 A）的核心。

1. 序言

回焊炉炉温曲线（furnace temperature curve）反映了焊接过程中焊点的温度变化情况，直接影响焊点质量。可调因素一般有：炉温曲线峰值温度、升温速率、电路板上的温度分布、预热时间等。若回焊炉各小温区温度调节不良，会导致电路板变色变形、空洞、润湿不良等缺陷，因此优化炉温曲线设计对提高焊接质量与可靠性至关重要。

1.2 量子粒子群算法与本文思路

量子粒子群优化算法（Quantum Particle Swarm Optimization，QPSO） 由 Sun 等人基于量子力学提出：它把粒子搜索空间映射到量子空间，用薛定谔方程的波函数描述粒子状态。相比经典 PSO，QPSO 实现简单、搜索高效、收敛快、所需参数少，且全局搜索能力强，已广泛用于工程优化问题。

本文思路：以「加热因子最小」和「传送带速度最优」两个目标，对回焊炉炉温曲线做多目标优化设计，为存在目标冲突的温区温度设置提供一套解决方案。

Note

QPSO 为什么比经典 PSO 更适合这里：经典 PSO 的粒子按牛顿力学轨迹运动，容易聚死到局部极值；QPSO 假设粒子处于量子束缚态，位置由概率密度函数给出，粒子可以以一定概率"隧穿"到更远区域，天然具备更强的全局探索能力。炉温优化问题的目标函数（加热因子是温度曲线的积分）非凸且不可导，恰好是 QPSO 这类无梯度全局搜索的用武之地。

温区间隙为什么值得单列：相邻小温区之间存在 5 cm 的间隙，间隙内没有加热元件，温度只能由两侧温区的边界温度线性插值决定。先前李楠等人的工作忽略了这一点，导致模拟炉温曲线在温区过渡处失真。本文用一维稳态导热方程（式 2）显式求解间隙温度分布，使曲线在温区切换处平滑、可预测——这是模型层面的一个具体改进点。

2.2 基本假设

  • 忽略回焊炉内温度场的热辐射（thermal radiation）传热；
  • 电路板材料均匀、各向同性，内部无温差、温度分布均匀（即电路板本身可视为等温体）；
  • 电路板进入温区瞬间，其内部温度保持稳定不变；
  • 电路板厚度较小，沿厚度方向的热传导忽略。

2.3 热传导模型

各小温区温度恒定，若相邻温区无温差则间隙温度恒定，反之间隙内温度呈线性变化。回焊炉空间内物体的三维非稳态导热微分方程为：

$$ \rho c \frac { \partial T } { \partial \tau } = \frac { \partial } { \partial x } \left( \lambda \frac { \partial T } { \partial x } \right) + \frac { \partial } { \partial y } \left( \lambda \frac { \partial T } { \partial y } \right) + \frac { \partial } { \partial z } \left( \lambda \frac { \partial T } { \partial z } \right) + \dot { \phi } \tag{1} $$

解读：这是能量守恒的微分表述——左侧为单位体积内热量的时间变化率，右侧三项为 x/y/z 三个方向的热传导净流入，末项 $\dot{\phi}$（内热源生成热） 为单位时间单位体积内产生的热量。温度场 T 随空间和时间演化。

由于各间隙边界温度稳定，式 (1) 可简化为一维稳态无内热源导热方程：

$$ \frac { \partial ^ { 2 } T } { \partial x ^ { 2 } } = 0 \tag{2} $$

解读：稳态（时间项为零）+ 无内热源 + 常物性 + 只沿传送带方向（x）变化，二阶导为零意味着温度沿 x 线性分布——这正是"间隙内温度线性变化"的数学依据。

对式 (2) 积分求解，可得温区间隙处的温度分布：

$$ T _ { i } = \varepsilon _ { i } x _ { i } + \beta _ { i } \tag{3} $$

解读：第 i 段间隙内温度是距离的线性函数，斜率 $\varepsilon_i$ 与截距 $\beta_i$ 由两端温区边界温度确定。

各温区间隙温度的线性分布可写成联立形式：

$$ \left\{ \begin{array} { l l } { T _ { i } = \varepsilon _ { i } x _ { i _ { \mathrm { c } } } + \beta _ { i } } \\ { T _ { i + 1 } = \varepsilon _ { i } x _ { ( i + 1 ) _ { \mathrm { s } } } + \beta _ { i } } \end{array} \right. \tag{4} $$

解读：用同一线性式描述第 i 温区末端（下标 c）与第 i+1 温区起始（下标 s）两个边界点，联立即可解出间隙温度线。其中 过炉速度（conveyor speed）$\nu$ 通过 $x = \nu t$ 把空间位置换算为电路板经历的时间——速度进入模型的关键通道就在这里：速度越快，电路板在每一温区的停留时间越短。

2.4 电路板焊接中心温度模型

电路板进入回焊炉瞬间内部温度保持不变，随后焊接中心温度随时间变化、趋近炉内温度场温度。将其简化为非稳态、有内热源的导热微分方程：

$$ \left\{ \begin{array} { l } { \displaystyle \frac { \partial t } { \partial \tau } = a \nabla ^ { 2 } t + \frac { \dot { \phi } } { \rho c } } \\ { \displaystyle a = \frac { \lambda } { \rho c } } \end{array} \right. \tag{5} $$

解读：t 为焊接中心温度，热扩散系数（thermal diffusivity）$a = \lambda/(\rho c)$ 综合了导热能力与储热能力——a 越大，温度扰动传播越快。

焊接中心吸收的热量与焊接表面上的对流换热量相等（热平衡）：

$$ Q _ { \mathrm { a } } = Q \tag{6} $$

解读：中心吸收的热量全部来自表面换热，把"内部导热"与"表面对流"两个过程在热平衡意义上解耦——这是集总参数法的核心思想。

采用牛顿冷却定律（Newton's Law of Cooling）建立界面换热模型：

$$ c \cdot \rho \cdot V \cdot \frac { \mathrm { d } t } { \mathrm { d } \tau } = - h ( T ) A \left[ t ( h , \tau ) - T _ { i } \right] \tag{7} $$

解读：左侧为电路板整体（体积 V、比热 c、密度 ρ）温度变化所需的热量，右侧为表面面积 A 上由对流换热系数 $h(T)$ 驱动的换热通量。负号表示温差为正时热量从电路板流向炉内空气。温度变化速率正比于「板温与环境温差」——温差越大升温越快，这是指数趋近响应的来源。

令 过余温度（excess temperature）$\theta = t - T_i$，式 (7) 化简为：

$$ \mathrm { d } Q = \rho c V \, \mathrm { d } \theta = - h ( T ) t A \theta \, \mathrm { d } \tau \tag{8} $$

解读：把变量从绝对温度 t 换成过余温度 θ（相对环境），方程变成关于 θ 的一阶常微分方程，可直接分离变量积分。边界条件是进入第 i 温区时的初始温度：

$$ \theta ( i ) = t _ { i } - T _ { i } = \theta _ { i } \tag{9} $$

解读：进入每个温区的初始过余温度由上一温区末的状态衔接，温区之间通过这个初值条件串联。

综合求解，可得焊接中心温度随时间变化的解析表达式：

$$ t ( h , \tau ) = \left( t _ { i } - T _ { \infty } \right) \exp \left( - \frac { h ( T ) A } { \rho c V } \tau \right) + T _ { \infty } = t _ { i } \exp \left( - \frac { \tau } { R C _ { i } } \right) + T _ { \infty } \left[ 1 - \exp \left( - \frac { \tau } { R C _ { i } } \right) \right] \tag{10} $$

解读：核心公式：焊接中心温度按一阶指数响应逼近炉内温度 $T_\infty$，时间常数 $RC_i = \rho c V / (h_i A)$ 是「热容 ÷ 热导」之比——RC 越大，升温越慢（热惯性越大）。这正是集总参数法（Lumped Parameter Method）的经典结果：把分布参数系统凝练为一个带时间常数的一阶系统，形式上与电路中的 RC 充电曲线同构，因此文章取名为"RC"。由此逐温区递推即可得到整条炉温曲线，无需数值求解偏微分方程。

3. 多目标炉温曲线优化模型

加热因子（Heating Factor）指炉温曲线中温度从锡膏熔点上升到峰值温度所覆盖的面积，即液相线以上温度对时间的积分。本文采用无铅常规锡膏，熔点 $t_a = 217$ ℃。在焊接中心温度模型基础上，以加热因子最小与传送带速度最大为目标，用多目标量子粒子群算法优化。

3.1 目标函数 1：加热因子最小

$$ S _ { \mathrm { cover } } = \min \left( \int _ { \tau _ { \mathrm { a } } } ^ { \tau _ { \mathrm { max } } } \left( t ( h , \tau ) - t _ { \mathrm { a } } \right) \mathrm { d } \tau + \int _ { \tau _ { \mathrm { max } } } ^ { \tau _ { \mathrm { b } } } \left( t ( h , \tau ) - t _ { \mathrm { a } } \right) \mathrm { d } \tau \right) \tag{11} $$

解读：把焊接中心温度超过锡膏熔点 217 ℃ 的两段（升温段 $\tau_a \to \tau_{max}$ 与降温段 $\tau_{max} \to \tau_b$）对时间的积分相加。加热因子越小，说明过熔点时间越短、峰值温度越低，焊点受热损伤的风险越小——它比单一峰值温度更能综合刻画"热应力总量"。

3.2 目标函数 2：最优传送带速度

$$ V _ { \mathrm { best } } = \max \nu \tag{12} $$

解读：在满足制程界限的前提下使过炉速度最大。速度直接决定产能，但速度越快，曲线整体被"压扁拉长"，容易出现峰温不足或过熔点时间不足——这正是与目标 1 冲突的根源。

3.3 约束条件

约束包括：传送带过炉速度限值、炉温曲线峰值温度、焊接中心温度变化速率、预热时间、焊接区域温度超过熔点的时间。速度限值为：

$$ 6 5 \, \mathrm { cm/min } \leq \nu \leq 1 0 0 \, \mathrm { cm/min } \tag{13} $$

解读：过炉速度被限制在 65–100 cm/min 工艺窗口内。炉温曲线需满足的制程界限见表 2。

4. 量子粒子群算法

QPSO 把粒子的搜索空间从经典空间转化为量子空间，用薛定谔方程的波函数描述粒子状态。粒子在局部吸引子附近聚集，其位置由下式给出：

$$ p _ { oj } ( d ) = \varphi _ { oj } ( d ) G _ { oj } ( d ) + \left[ 1 - \varphi _ { oj } ( d ) \right] Z _ { j } \tag{14} $$

解读：局部吸引子 $p_{oj}(d)$ 是粒子的个体最佳位置 $G_{oj}$ 与种群全局最佳位置 $Z_j$ 的加权合成，权重 φ 是 (0,1) 上的均匀随机数——它决定了粒子向"自己经验"还是向"群体经验"倾斜。

粒子依量子阱波函数给出的密度函数向阱中心收敛，位置更新规则为：

$$ X _ { oj } ( t + 1 ) = p _ { oj } ( d ) \pm u \Big| Pbest _ { j } ( d ) - X _ { oj } ( d ) \Big| \ln \left( \frac { 1 } { r } \right) \tag{15} $$

解读：新位置 = 吸引子位置 ± 一个由平均最优位置与当前位置差值决定的随机步长。u 为收缩扩张因子（控制收敛速度），r 为 (0,1) 随机数。±号与 ln(1/r) 组合使粒子能以概率"跳出"当前区域——这就是量子隧穿效应的数值体现。

其中 Pbest 为粒子群的平均最优位置：

$$ Pbest _ { j } ( d ) = \frac { 1 } { M } \sum _ { o = 1 } ^ { M } P _ { oj } ( d ) \tag{16} $$

解读：对所有粒子个体最优位置取平均，M 为种群规模。这一"均值中心"是 QPSO 与经典 PSO 的关键差异：经典 PSO 只向个体/全局最优点移动，QPSO 额外引入群体均值引力，使收敛过程更平滑。

为避免人为因素影响最优方案选择，用模糊隶属函数从帕累托最优解集中挑选：

$$ \left\{ \begin{array} { l l } { \varphi _ { l } ^ { k } = \frac { f _ { k } ^ { \mathrm { max } } - f _ { k } ( x _ { \mathrm { m } } ) } { f _ { k } ^ { \mathrm { max } } - f _ { k } ^ { \mathrm { min } } } } \\ { \varphi _ { k } = \frac { \sum _ { k = 1 } ^ { N _ { \mathrm { obj } } } \varphi _ { l } ^ { k } } { \sum _ { l = 1 } ^ { N _ { \omega } } \sum _ { k = 1 } ^ { N _ { \mathrm { obj } } } \varphi _ { 1 } ^ { k } } } \end{array} \right. \tag{17} $$

解读：多目标优化不会给出唯一解，而是一整条 帕累托前沿（Pareto Front）。模糊隶属度把每个解在各目标上的表现归一化到 [0,1] 再求和：某个候选解在两个目标上都"接近各自最优"时综合满意度最高。对所有 Pareto 解计算 φ 后取最大值对应的方案作为最终结果——无需人为决定两个目标的权重，这是无偏好多目标决策的标准做法。

Note

算法流程（8 步，对应正文）：① 设定外部档案容量 $L_{max}$ 与种群规模 M，按制程界限生成可行解并随机初始化；② 按式 (11)(12) 算适应度，非劣解入外部档案，确定个体/全局最优；③ 按式 (15)(16) 更新粒子状态；④ 校验粒子是否满足制程界限，不满足则丢弃；⑤ 按 Pareto 原则更新非劣解集；⑥ 用拥挤度排序法维护外部档案规模；⑦ 检查终止条件（最大迭代次数）；⑧ 用模糊规则选最终方案。拥挤度排序保证 Pareto 前沿上的点分布均匀，不会挤成一团。

依据第 2 节热传导模型仿真得到回焊炉温度场的温度分布曲线（图 1）；以基本参数为基础，用 QPSO 与最小二乘法拟合焊接中心温度模型中的待定参数，获得模拟炉温曲线与测试数据对比（图 2）；焊接中心温度变化分布仿真结果见图 3。由图 2~图 3 可见，模拟曲线与实测曲线走势大致相同且收敛较好，验证了模型的合理性。

为验证多目标优化模型的有效性，另设 3 组对比：① 仅以加热因子最小为目标；② 仅以最优过炉速度为目标；③ 双目标同时优化。结果见表 3：仅追求最大速度会使加热因子升至 2931.56（过熔点时间过长，焊接质量下降）；仅追求最小加热因子则速度降至 94.05 cm/min（效率受损）。双目标同时优化得到速度 95.55 cm/min + 加热因子 1753.04，两目标均接近各自最优——单一目标优化的代价正是牺牲另一目标。

6. 结论

  1. 以回焊炉炉温曲线为研究对象，在满足制程界限与工艺要求前提下，以传送带速度最优与无铅锡膏加热因子最小为目标，用量子多目标粒子群算法完成炉温曲线优化设计，获得了最大过炉速度与各温区最优温度。
  2. 用 QPSO 与最小二乘法拟合出焊接中心温度模型待定参数，模拟炉温曲线与实测曲线走势大致相同、收敛良好，验证了模型可信。
  3. 双目标优化后过炉速度 95.55 cm/min（接近上限）、加热因子最小 1753.04；炉温曲线整体先升后降，峰值 240.01 ℃（接近下限）——同一模型同时保证产能与焊接质量。

核心要点总结

  1. 建模巧思：用集总参数法把焊接中心温度写成带时间常数 RC 的一阶指数响应（式 10），免去求解偏微分方程，参数由 QPSO + 最小二乘拟合标定。
  2. 间隙显式建模：用一维稳态导热（式 2–4）显式求解温区间隙的线性温度分布，修复了既往模型在温区过渡处失真的问题。
  3. 双目标而非单目标：加热因子最小与过炉速度最大天然冲突，单目标优化必然牺牲其一（实测：只求速度 → 加热因子 2931.56；只求加热因子 → 速度 94.05）。
  4. 无偏好决策：模糊隶属函数从 Pareto 前沿选点，避免人为指定目标权重。
  5. 结果贴近工艺窗口：速度 95.55 cm/min、峰温 240.01 ℃、速率 −2.18~+2.95 ℃/s，全部紧贴制程界限，验证优化器在可行域边界收敛。
  6. 可直接落地：表 5 给出 11 个温区的最优温度设定（如回流区 8~9 温区 264.81 ℃），工程人员可直接作为工艺参数参考。
